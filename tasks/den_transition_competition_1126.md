# DEN 同期稳定对照与语义转移

一次变化判断同时回答两个问题。这个区间有没有改变地类，变化成立时两端分别是什么。在保持旧有类别概率不变的情况下，直接对两期的边际概率取最大值也可能产生新的报警。因此本轮先从影像证据得到各区间的变化分数，再在给定报警序列时求最可信的八期地类路径。只要一个区间被判稳定，求出的路径在该区间就使用同一个类别。

在“裸土→水”的方向上，共享模型为 36 个类别对打分。竞争组把该方向的得分与“始终裸土”和“始终是水”中得分较高的一个相比。对照组对变化类别对与稳定类别对各自汇总总分后比较。两组共享形状、初始化、优化预算以及时序路径损失，均用同区同期不同图块的稳定实例训练。训练时用八期标签构造端点对。缺少标签的日期将路径似然分成数段。

| | 常规的变化组对稳定组 | 每个方向对自己的两种稳定解释 |
| --- | --- | --- |
| 仅使用现有 PSE/A1 的单期局部特征 | `local_mass` | `local_rival` |
| 保留其余局部特征，用原波段和单位长度光谱替换等宽通道 | `spectral_mass` | `spectral_rival` |

## 数据与评估口径

- 官方 DEN 47 个训练区、10 个不同验证区与固定的八个评价月 [0,3,6,9,13,16,19,23]。输出记录划分、输入权重、代码以及逐区特征的 SHA256。每次实际用固定 128×128 图块运行已有的 PSE 家族主干。每区训练抽 9 块，跨区验证抽 16 块，默认间隔 16 像元。
- 四组共用同一个冻结主干及同一批标签。四臂的输入通道数量与可训练参数量相同。原始波段与单位长度后的光谱都是当期原输入的变换。源区校准折在本轮拟合中留出，旧主干曾使用全部训练区。
- 主要评价是其他地区验证样本上，同一报警位置与同一稳定像元误报率下的严格转移 F1、准确方向数及每类、每地区收益。严格转移要求两个端点都正确。额外列源区固定误报阈值下的 SCS、mIoU、真变化召回、稳定误报率和 AP。验证集同误报操作点是诊断曲线。
- 源区 10% 误报操作点、预算每臂 500 次更新，以及 5%、10%、20% 验证误报诊断点均在出结果前确定。只有在同误报或同位置的两端识别真的变好时，才支持该结构。进入整图实验前，还要用已知裸土变水高集中地区之外的地区与其他变化类别复核。最终论文表用冻结配置的完整正式测试、原版 ST3DUNet 与强基线以及多种子比较。

## 在现有机器上运行

使用已有 DEN 环境，Python 3.10 或更新版本、PyTorch 2.3 或更新版本、NumPy 和 Pillow。优先选自己的 T34 单源 DEN-Planet PSE 第 120 轮，缺失时用已留存的第 250 轮。若只有 DEN-Planet M1/M2/M3 或 PSE+BN，可用兼容的真实权重，记录来源与实际轮次。所有比较仍在同一个输入权重内完成。脚本会按权重键推断普通配置，并严格加载。

```bash
python -B -u -X utf8 run_pilot.py --sensor planet --seed 43 --data "<DynamicEarthNet>" --checkpoint "<已有PSE权重.pth>" --out "<新作业目录>" --device cuda:0
```

找不到兼容的真权重时，用相同公开训练数据先训一个短预算 A1。这个模型用来做本机配对诊断，轮数和权重来源在回执中说明。

```bash
python -B -u -X utf8 warm_start.py --sensor planet --seed 43 --data "<DynamicEarthNet>" --out "<新A1目录>" --steps 768 --device cuda:0
```

生成 `<新A1目录>/last.pth` 后交给上面的命令。乙端的两个命令均用种子 44。本机 DEN-S2 使用已知 M3 种子 42 第 120 轮里的 A1 骨干。

发回 `runner_status.json`、`fit/protocol.json`、`fit/results.json` 与 `train.log`，同时注明读到的提交及实验包 SHA256。开始时回报机器资源、数据存在与否、选了哪个已有权重。看见第一条 `[FIT]` 更新再报告训练启动。
